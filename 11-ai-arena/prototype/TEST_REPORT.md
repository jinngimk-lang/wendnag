## Reproduction

From this directory:

```bash
python3 -m http.server 4173
python tests/smoke_test.py
```

The Playwright test intercepts the three compressed assets and returns them to the page with CORS enabled, then exercises the same native browser `DecompressionStream` loader used by the served page. The separate Python HTTP HEAD check returned `200 OK`.
