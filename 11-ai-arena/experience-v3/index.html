SIMULATION CONTRACT

公平模拟与独立账户边界

六个 Agent 共享同一条合成价格路径、相同初始资金、交易费用、滑点与仓位上限，但每个 Agent 拥有独立现金余额、股票持仓、净值轨迹和操作账本。不存在中央资金池，也不存在 Agent 之间的资金转账。

当前没有接入真实公司财报、公告、新闻、市场行情、外部 LLM Agent 或券商。公司文本只作为演示任务标签和可复现随机种子的一部分。所有观点、事件、情绪、成交与收益均为合成数据。

未来真实数据版本必须保存来源、发布时间、抓取时间、授权信息、时点快照与引用；严禁未来数据泄漏。模拟成交与真实交易必须严格分离。
