# Pitch Deck Research Archive / BP 研究资料索引

本目录不是“未经授权的 BP 原件镜像站”。它记录本轮 10 份主样本的**原始/官方访问入口、材料性质、可信等级和归档权限**，并将中文研究笔记放在 `06-analysis/bp-benchmark/company-notes/`。

用户要求把找到的 BP 打包。本轮核验后发现：多份机器人/智能硬件 investor presentation 明确带有 Confidential / Proprietary / 禁止未经同意复制或分发的条款；部分早期创业 deck 虽公开可读，但没有明确开放再分发许可。因此最终资料包采用以下方式：

- 收入全部 10 家公司的研究档案；
- 每份研究档案提供原始/最高可信访问链接；
- 英文融资材料均采用“English paraphrase → 中文释义”紧邻对照；
- 不重新上传或分发整份版权/传播权限不明确的原版文件；
- OpenAI、Anthropic 因未发现可验证的官方早期完整 pitch deck，只收官方融资叙事补充，不用仿制 deck 充数。
