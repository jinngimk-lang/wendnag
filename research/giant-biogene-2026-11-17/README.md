# 巨子生物 11-role / 10-angle / Red-team 尽调工作区
- **截至日期**：2026-11-17；香港上市主体 Giant Biogene Holding Co., Ltd（2367.HK），中国业务主要位于陕西西安。
- **读档顺序**：`STATE.md` → `EXECUTIVE_REPORT.md` → `FACT_LEDGER.md` → `SOURCES.md` → 对应 `agents/Axx.md` → `redteam/A11.md` → `OPEN_QUESTIONS.md`。
- **方法说明**：11 个角色是分离研究视角及可追踪的工作产物；本轮由同一 AI 在不同角色下顺序研究、交叉挑战，**不是 11 个独立运行的模型实例，更不是十一名人类专家**。红队在实质结论之后独立质询假设，不能宣称外部审计认证。
- **结论层级**：A = 上市主体公告/审阅报告等一手披露；B = 可核查第三方研究/对照；C = 假设、推断或未查明。招股书、国家药监局原始注册资料及完整临床底稿仍待强化验证。
- **边界**：仅研究公开资料；不含未公开渠道调查、投资建议、内幕信息、对任何个人的不当指控；不把公司的自我宣传或行业预测当作独立验证。
- **仓库隔离**：本项目以独立子目录存在，不改动根目录 BP 的 PROJECT/STATUS，不影响公司商业计划书工作流。
- **可复现**：`python scripts/check_metrics.py` 核对公开财报数字推算。无需第三方依赖，亦可在 venv 内运行。
