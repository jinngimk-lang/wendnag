# A10 预审反证与风险 — 2026-11-23
**A10仍是“预审框架 + 本轮人工对抗检查”，不是独立后台Agent已经完成。**
| 优先级 | 被挑战的说法 | 反证/结论与必须再取的证据 |
|---|---|---|
| P0 | “秦商总会有6万家企业，所以可直接销售给6万家” | E02属于机构口径，未提供可授权名录、联系渠道、预算；只能用于说明潜在网络规模，不能乘以ARPU做营收预测 |
| P0 | “只要有清欠小组，会员普遍欠款” | E01只证明总会有协调机制，不证明具体会员当前逾期。须抽取愿意参与企业真实应收证据和账龄 |
| P0 | “经开区座谈企业都是正式会员且即将签约” | E03只证明活动对接；与正式会员身份和采购意图是三种事实，不能混写 |
| P0 | “AI已具备医疗器械自动监管放行能力” | PDF中的流程能力仅为方案宣称；监管合规、数据安全、专业终审、模型漏检与责任分配必须测 |
| P1 | “两次可复美金额可叠加、属于同一案” | E12与E13案件事实/时间/来源未取得同一案号；禁止合并或重复计算 |
| P1 | “某龙头企业一定需要我们提供的系统” | 大企业可能已有ERP/QMS/合规引擎，必须证明无法在其现有工具内解决的增量痛点 |
| P1 | “出海泛化合同审核能覆盖所有国家” | 地区/商品/制裁/贸易规则差异重大，需当地律师及合法法规来源，人审 |
| P1 | “打假Agent能自主查处商家” | 不能自动采取执法、处罚或侵入性取证；只能在合法权限下收集公开线索并交企业法务复核 |
## 关键未核实四问
- 资金：哪个企业已有可脱敏逾期/回款痛点？CFO是否确认成本和预算？
- 医械：客户既有QMS与合规系统能覆盖多少？公司有何可量化差异？
- 工程：变更、验收、付款数据是否可用且能以一个项目组成金标准？
- 技术：LegalLens/AragonTeam/AegisClaw哪些功能已商用并安全可复验？
任何一问不能回答，即便评分超过90也不应该宣称确定机会。
