# 十 Agent 工作包 — 分工、输出、红队
本文件定义可交给10个独立研究智能体/人工研究员执行的任务。**本轮尚未声称10个真实Agent已运行。** 每个任务保存结果时需新增 `agents/Axx.md`，不能拿下文任务设计充当已完成报告。
| ID | 职责 | 关注的证据源 | 必须输出 / 证伪 |
|---|---|---|---|
| A01 | 商会治理和企业关系 | 总会/政府活动、工商主体、协会公开信息 | 具名企业与关系类型；证伪“参加活动=正式会员” |
| A02 | 产业、财务和现金流 | 年报/应收/逾期账款/付款规则 | 现金流风险场景、账款基线与预算负责人；证伪“所有企业缺现金” |
| A03 | 司法、商标和侵权事件 | 法院/检察/公安/知产/平台合法公示 | 去重案件时间线和证据需求；证伪“行业打假=该企业假货泛滥” |
| A04 | 医药器械和监管 | 药监法规/注册/质量/召回 | 对质量文件规则的具体检验点与人审边界；证伪“规则已可完全自动化” |
| A05 | 汽车/制造/工程 | 招投标/质量通报/交付/合同条款 | 供应商/验收/变更风险链；证伪“存在现成ERP则必需新系统” |
| A06 | 出海/贸易 | 国际贸易活动、市场准入、仲裁、合同 | 国家/商品/环节三维合规差异；证伪“本地规则能直接跨境复用” |
| A07 | 农业食品/能源 | 监管、认证、批次、能源工程 | 高代价环节和已有追溯系统差距；证伪“重做追溯=价值” |
| A08 | 真实订单/采购商机 | 招标、采购公告、客户订单、企业公告 | 具名公开采购信号及真伪；证伪“收集名单即产生订单” |
| A09 | 产品架构/POC | Aegiston产品证据、公开方案、接口清单 | 主产品、依赖/需定制能力、POC与退出条件；证伪“报告宣称即已产品化” |
| A10 | 独立反方/成交审查 | 不依赖A01-A09的原始公开证据 | 针对最优3个提强反例与淘汰条件，强制检查“谁付钱” |
## 公用交付模板
1. 核实事实：事实ID、公开URL、发表/事件日期、主体、证据等级、口径和局限。
2. 需求推断：必须标【假设】；为何决策层愿付费，不可凭直觉。
3. 最有力反方：现有软件/服务商/内控已解决吗？谁能否决项目？发生概率多高？
4. 公司能力：可直接复用与尚未开发部分分别列举。
5. 实验：人工基线、抽样策略、金标准、召回/误报/耗时和审计指标；法务/质量等人终审。
6. 接触路径：关系性质、采购角色（未知则未知），禁止写私人联系方式。
7. 输出置信度：confirmed-public / supported-inference / hypothesis / unsupported；没有结果时列待查而非凑结论。
## 研究闭环
来源→事实ID→各Axx笔记→ATLAS→A10反证→STATE→独立分支/PR。优先扫描各源的**最新更新**，同一案件按关联键去重，事件时点与发布时间分开，金额性质分开。
