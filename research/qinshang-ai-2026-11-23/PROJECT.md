# PROJECT — 秦商总会 AI 赋能商业机会研究（独立子项目）
**委托目标**：西安智瞳安宇科技有限公司面向秦商总会及其联系企业，寻找值得决策层重视且公司可以交付的重大真实痛点。
## 工作原则
1. **证据比方案先行**：企业财报、监管官网、法院/检察/公安、商会活动、招投标、供应链公开信息；不得只搜新闻标题。实体须按名称/品牌/子公司/历史名称扩展检索并跨来源去重。
2. **全面发现但严苛收敛**：资金、质量安全、商誉、海外准入、交易机会等跨行业扫描；不为了数量编造方案，打假只是典型检索漏项。
3. **产品事实边界**：本地案例 PDF 第10–12页称 LegalLens 支撑规则/合同与合规，AragonTeam 支撑跨部门流程/文档，AegisClaw 支撑多智能体监测/生成。以上属于**客户方案中的产品宣称**，其生产就绪度、真实API/私有化、安全审计与实施条件仍需由智瞳安宇研发负责人复核。不得把报告推断当作客户已部署事实。
4. **机会最低交付格式**：事件事实/来源 + 未证实的业务痛点假设 + 错一次损失类型 + 预算主体与负责人（未知即未知） + 现有解决方案差距 + 主承接产品 + 所需新增能力 + 数据授权 + 4–8周 POC 金标准/人工基线/失效与退出条件 + 反证。
5. **评分只能帮助排队**：五维 30/20/20/15/15，1–5分；并行设置客户授权/合法性、数据可得、可交付、明确采购方四个硬门槛。硬门槛未通过，永远不能标“确定商机”。
6. **尊重第三方**：公开案例不能直接当成个体企业的违法认定；不得自动执法、未授权访问、批量收集隐私；涉及医疗、法律、金融专业结论均有人终审。
7. **可公开性**：此库公开，只保存经核实的公开事实、来源链接、非敏感方法论及本公司可公开能力；未授权 PDF 原文不上传。

## 两条销售模式
(A) 总会推荐会员企业，真正的客户自行授权、付费试点、验收；(B) 总会若有明确预算/采购权限，另行调研总会企业服务系统。不可假定总会已同意、已拨款或拥有会员敏感数据共享权。
## 成功门槛
先争取10家有效访谈、3个可演示场景、1–2个有预算与愿意付费的试点（**目标值，非成交事实**）。优先瞄准可审计损失避免、回款、验收周期或市场准入，而不是通用聊天机器人或内容生成。
