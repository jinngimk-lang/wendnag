# 中国 AI / 机器人 Pre-A BP 外部参考网站索引

> 结构基准：华擎（武汉）通信科技 22 页 Pre-A 融资 BP
>
> 原始 PDF：https://www.kicchina.org/uploadfile/2019/1224/20191224094617365.pdf
>
> 本项目把华擎的线性融资叙事作为筛选尺：**项目总览 → 产品/应用 → 市场/痛点 → 核心能力 → 竞品/壁垒 → 团队/客户 → 融资 → 资金用途 → 经济结果 → 里程碑**。以下网站按“能否找到与该结构接近、可核验的真实 BP/路演材料”排序。

## A 级：优先查原 PDF / 原路演附件

### 1. KIC China（在华韩国创新中心）公开附件库
- 主站：https://www.kicchina.org/
- 特点：历史活动、路演和项目附件中经常直接挂 PDF；对早期硬科技、AI、医疗科技、制造业项目尤其有用。
- 与华擎相似度：**最高**。华擎原 BP 就来自这里。
- 建议搜索：`site:kicchina.org/uploadfile 商业计划书 人工智能 pdf`、`site:kicchina.org/uploadfile 融资 机器人 pdf`、`site:kicchina.org/uploadfile 本次拟融资 人工智能 pdf`。
- 已核验样本：
  - 华擎（武汉）通信科技 Pre-A BP：https://www.kicchina.org/uploadfile/2019/1224/20191224094617365.pdf
  - 基于人工智能产前超声辅助诊断项目：https://www.kicchina.org/uploadfile/2020/0107/20200107031957240.pdf
    - 材料直接写明拟融资 1000 万元、受让 10% 股份，并给出工资、市场、资质、设备等资金分配。
  - 速找网商业计划书：https://www.kicchina.org/uploadfile/2020/0108/20200108104558907.pdf
    - 制造业智能平台 / SaaS / 大数据服务，适合研究“产品 + 产业链服务 + 平台扩张”的表达。
  - 新松集团介绍 PPT：https://www.kicchina.org/uploadfile/2019/1224/20191224085712816.pdf
    - 不是 Pre-A BP，但“产品销售 → 智能服务 → 数据/平台收入”的价值迁移表达值得参考。

### 2. 创业邦 Cyzone 历史 PDF 附件
- 主站：https://www.cyzone.cn/
- 特点：早年 Demo Day / 路演资料有不少 `uploadfile/...pdf` 原始附件；机器人、智能硬件、企业服务的早期材料较多。
- 与华擎相似度：**高**，特别适合找 2015–2020 年左右的早期融资 Deck。
- 建议搜索：`site:cyzone.cn/uploadfile 路演BP 机器人 pdf`、`site:cyzone.cn/uploadfile 商业计划书 人工智能 pdf`。
- 已核验样本：
  - 可以科技 KEYi / CellRobot：https://www.cyzone.cn/uploadfile/2017/0210/20170210111322350.pdf
  - 沈阳通用机器人：https://www.cyzone.cn/uploadfile/2017/0217/20170217095047257.pdf
- 研究重点：项目亮点、核心产品、订单/收入、团队、融资历史通常放得很前，接近用户偏好的“投资人快速判断”节奏。

## B 级：用于按 Pre-A / AI / Agent 找真实项目，再追原文件

### 3. 蝶动洞察 / 1查就有（1c9u）BP 资料库
- AI 分类：https://www.1c9u.com/bp/industry/artificial-intelligence
- BP 总库：https://www.1c9u.com/bp
- 特点：可以直接按“人工智能、企业软件 SaaS、Pre-A、融资金额”筛选；页面通常给出项目介绍、轮次、金额、页数等元数据。
- 与华擎相似度：**作为线索库很高**，但来源混合，不把其页面自动等同为官方原件。
- 已核验例子：
  - 微探智能：Pre-A 1000 万，工业 CT + GPU/CNN：https://1c9u.com/bp/p/7652
  - Revol：Pre-A 1000 万，18 页，AI 原生数字音频工作站；目录可见。
  - 播知科技：Pre-A 2000 万，16 页，外贸企业 AI 商业智能体；目录可见。
  - 乾知智能：Pre-A 2000 万，政企内控审计智能体；AI 分类第 2 页可见。
- 使用规则：先用这里发现项目，再追公司官网、创始人、投资机构、活动主办方或 PDF 原托管站核验。

### 4. 36氪 PitchHub
- 主站：https://pitchhub.36kr.com/
- 特点：融资阶段、融资历史、投资方、项目定位更新较快；适合核验一个项目是否真的处于 Pre-A / Pre-A+。
- 与华擎相似度：**不是 BP 原件库，而是融资事实校验层**。
- 已核验例子：
  - AI 企业智能获客 Agent：Pre-A：https://pitchhub.36kr.com/project/3830051495502848
  - 聆心智能：Pre-A：https://pitchhub.36kr.com/project/2012197088051206
  - 千寻智能：有完整 Pre-A / Pre-A+ 融资历史：https://pitchhub.36kr.com/project/3051237195749764
- 使用规则：用于“轮次 / 公司定位 / 投资方”交叉验证，不把项目简介当作原 BP 文本。

## C 级：适合看完整 BP 页面结构，但版权/来源必须二次核验

### 5. 搜弘文库（wenku.chochina.com）
- 机器人 / BP 文档入口：https://wenku.chochina.com/
- 特点：大量 PDF/PPT 的页面级预览、页数、文件名、摘要；可以看到不少真实路演 BP 的内容结构。
- 与华擎相似度：**高到中**，适合研究版式和页面顺序；但上传者和授权状态混杂，因此只作为研究入口。
- 已核验例子：
  - 沈阳通用机器人路演 BP：https://wenku.chochina.com/doc/129540.html
  - 芯算一体融资计划书（边缘计算 AI 盒子 + 多模态大模型，30 页）：https://wenku.chochina.com/doc/165945.html
  - Roby 智能服务机器人 BP：https://wenku.chochina.com/doc/129571.html
  - 未感科技无人驾驶 / 激光雷达 BP：https://wenku.chochina.com/doc/131841.html
- 使用规则：可以做“页面职责 / 叙事结构 / 视觉密度”研究，不从第三方文库绕限制批量下载或重新分发整套材料。

## D 级：官方/高校/政府“商业计划书结构”参考

### 6. 高校与政府创新创业竞赛附件
这类不是公司真实融资 BP，但可用于检查中国评审方对 BP 完整性的基本期待，尤其是执行摘要、产品、市场、商业模式、融资与财务的必要模块。

- 全球校园人工智能算法精英大赛 · AI+创新创业 BP 大纲（上海理工大学托管 PDF）：
  https://cxcy.usst.edu.cn/_upload/article/files/e4/53/5db8b58d4e90963cdaa92a0811ba/3ff03484-ec64-4efa-83a2-596cc3a903a7.pdf
- 广东“众创杯”2026：人工智能 OPC 专项赛要求完整商业计划书：
  https://www.gz.gov.cn/zwfw/zxfw/jyfw/content/post_10712271.html

与华擎的关系：只用来做“模块完整性检查”，**不应作为投资人版主 Deck 的信息密度模板**。竞赛 BP 往往比 VC Deck 更长、更像申报材料。

## 当前推荐阅读顺序

如果目标是继续寻找“和华擎这份 Pre-A BP 一样直接、融资味强、技术公司也能看懂”的材料：

1. **KIC China** — 先扫所有可直接打开的项目 PDF；
2. **创业邦 Cyzone** — 补机器人、智能硬件、企业服务老路演 Deck；
3. **1c9u** — 用 Pre-A + AI/Agent/SaaS 快速发现候选；
4. **36氪 PitchHub** — 核验候选公司的真实轮次与融资历史；
5. **搜弘文库** — 只在需要看页面结构、版式和旧 BP 时使用；
6. 高校/政府竞赛附件 — 仅做结构完整性补充。

## 对智瞳安宇后续筛选的硬标准

新样本进入“核心参考”前，至少满足以下 4 条中的 3 条：

1. Seed / Pre-A / Pre-A+ / 早期 A，阶段与智瞳安宇可比；
2. 能看到原 PDF/PPT 或高完整度逐页预览；
3. 前 3–5 页能快速回答公司是谁、卖什么、已证明什么；
4. 融资、资金用途、下一阶段里程碑是主线的一部分，而不是最后一页形式化出现。

额外加分：
- 企业 AI / Agent / 软件 + 私有化部署；
- 机器人 / 智能硬件 / 工业 AI；
- 有真实客户、订单、收入、部署或量化效率数据；
- 技术壁垒能翻译成客户价值、成本或交付效率。

## 版权与真实性规则

- “网页能打开”不等于“允许二次分发”。
- 官方/主办方原 PDF 优先；第三方文库仅做研究线索。
- 对标分析可以保存 URL、元数据、页面职责、事实摘要、短引文；没有明确授权的完整 BP 不重新上传。
- 每份候选材料都需要单独标记：`原始/官方`、`第三方镜像`、`轮次可核验`、`是否允许再分发`。
