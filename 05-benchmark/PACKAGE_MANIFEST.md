## 为什么资料包不直接包含所有原始 Pitch Deck PDF

本项目发现的 Figma、Scale AI、Perplexity、字节跳动早期 BP 等完整 deck 多由第三方网站归档或转载，未发现足够明确的再分发授权。Anthropic 的 Series C deck 主要由媒体披露，OpenAI 的第三方 deck 索引也不是官方可下载文件。

因此，为避免把来源不明或受版权保护的整套文件重新打包分发，本项目采用：

- 原始来源 URL
- 材料元数据
- 结构/逐页研究摘要
- 少量英文短语 + 中文解释
- 对智瞳安宇的可迁移建议

对于官方公开、监管披露或明确允许下载的材料，用户可通过研究卡中的官方链接直接取得最新原件。

## 英文材料处理规则

研究卡采用“英文短语/核心表达 + 中文解释”，帮助中文团队理解融资表达；不制作未获授权的整套英文 deck 的逐字中文翻译副本。

## 可下载资料包

聊天交付的 ZIP 包与本目录保持同一研究结构，包含来源索引、10 家研究卡、对比矩阵和改版建议。若未来获得某份原始 deck 的明确再分发许可，可将其加入 `05-benchmark/materials/` 并更新本清单。
