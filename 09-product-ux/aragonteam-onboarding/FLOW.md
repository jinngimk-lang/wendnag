## 主路径

01 → 02 → 03 → 04 → 05。

- 本地导入：05 → 06 → 07 → 08 → 12。
- Git 同步：05 → 09 → 10 → 11 → 12。
- 空白开始：05 → 12。
- 每个后续页面可返回上一步，完成页可以返回入口。

## 设计约束

使用 Noto Sans SC 和品牌色 #25211F / #E98B67 / #F8F7F4。第一步创建账户，第二步选择偏好，第三步团队命名，第四步邀请，第五步连接数据。文本、卡片、表格、按钮和导航均为原生可编辑 Figma 图层。原型连线为演示性质，不代表已对接生产系统。
