# AragonTeam v7 — 项目协作房间、会议演示与个人资料 UI 交付存档

日期：2026-10-23；工作分支：`jinngimk-lang-AT`；交付文件：根目录 `index.html`。

## 目标、输入和边界

- 用户要求**仅制作可交互前端 UI 原型**，暂不做后端，也不调用真实 Agent、MCP、聊天、音视频、录制或屏幕共享。
- 四个一级入口保留：智能体、项目、团队、个人（另有底部设置）；项目七项子菜单维持：项目管理、需求看板、BUG看板、文档、代码仓、建议、版本。
- 白底、深蓝文本、橙色主操作；默认界面简洁，复杂信息按需展开。不可因为“功能完整”而增加多层常驻侧栏。
- 图像参考：用户上传的 Legallens 项目房间、多人会议与 AI 纪要、个人资料截图；基线参考 `docs/UX_V7_GROUP_ROOM_ANALYSIS.md`、`docs/UX_V6_REVIEW.md`。
- **截图仅是视觉与信息结构参考**，不是已验证的线上交互；需要真实媒体、服务端和鉴权的功能全部明确标注为本地演示。

## v7 已实现的前端交互

### 项目协作房间（智能体 → 群聊）
- 房间选择器代替永久第三层导航；支持点击外部及 Escape 关闭，保留新建群聊、频道数据和参与者弹窗。
- 中间聚焦讨论及工作动态，按 全部/讨论/Agent动态/系统 分类；系统记录按需展开；Agent 运行卡可展开查看模拟步骤。
- 右侧按 任务/成员 切换，笔记本及手机使用可打开的详情抽屉。任务点开复用原项目任务抽屉，不单独制造第二份任务。
- 保留引用、回复、@参与者选择、发送本机演示消息、消息转需求确认、关联项目/需求/文档/代码仓快捷入口。

### 前端演示会议
- 展示当前群聊成员与 Agent、模拟麦克风/摄像头开关、提示不可用的分享与录制、演示会议聊天。
- 「AI 纪要」是固定**示例纪要**；行动项可勾选并在 Tab 切换后保留；结束会议有二次确认，可取消。
- 不申请设备权限、不录制、不连接服务端。界面提示“演示”。

### 个人资料
- 单独入口提供查看与本机编辑姓名、职位、邮箱/联系电话、地点、个人介绍、工作状态及通知偏好、语言偏好。
- 引导用户不要填写真实敏感资料；不实现假密码修改或账号会话管理；可一键回到“我的工作”及团队。

- v7 首轮回归发现「会议行动项」勾选数据已更新但浏览器默认动作被拦截，复选框视觉上不保持选中。已修复 native checkbox click 处理。
- 房间菜单加入点击外部关闭与 Escape 关闭，并恢复触发按钮焦点。
- 本地 Chromium + Playwright 页面注入模式：**320/390/768/1024/1440/1664px 六种屏宽 PASS**，无捕获 JavaScript 页面错误和文档级横向溢出；涵盖群聊筛选、执行卡、消息、@、任务抽屉、会议聊天、行动项、结束、个人资料与原项目页。
- 对抗测试：**390/1440px PASS**，检查四一级入口/项目七子项不变、菜单外部与键盘关闭、恶意 HTML 只作为文本展示、消息转需求确认、会议行动项 Tab 切换状态、个人资料文本转义。
- v7 JS 通过 `node --check`。
- 实际在用户 Chrome/Edge 打开本地 HTML 后的`file://`刷新持久化、真实媒体功能及完整 WCAG 评估尚未验证，不能标成已通过。
- 本次测试程序为本地交付：`AragonTeam_v7_基础回归.py`、`AragonTeam_v7_对抗回归.py`；运行要求 Python Playwright + Chromium。原仓库 `tests` 下既有测试保留。

## 后续迭代协议

1. 每次先读取此文档、`docs/UX_V7_GROUP_ROOM_ANALYSIS.md`、`docs/UX_V6_REVIEW.md` 及 GitHub 当前 `index.html`，确认分支 SHA。
2. 不新建一级入口；项目七项保持不变，不回退团队、Agent 模板中心或个人工作台。
3. 用户每次审核后先找真实行为问题，再增量修改 HTML；复验 6 种视口、XSS 文本、会议状态、弹窗焦点与旧项目路径。
4. 不将 UI 演示与真实生产系统混淆；不以“已测试实时会议/已调用 Agent”描述尚未接后端的功能。
