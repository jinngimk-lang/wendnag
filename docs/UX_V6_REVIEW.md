# AragonTeam v6 — 精简协作工作台设计锚点与验收

日期：2026-10-23。工作分支：`jinngimk-lang-AT`；源文件：仓库根目录 `index.html`。

## 目标与不可变约束

- **仅做前端 UI/UX 原型**：无后端、无在线 Agent/MCP 调用、无真实聊天、无真实权限或计费数据。
- 四个一级导航保持：**智能体、项目、团队、个人**；底部设置入口保留。
- 项目菜单保持七项且不增减：**项目管理、需求看板、BUG看板、文档、代码仓、建议、版本**。
- 沿用深蓝字体、白底、橙色主要操作、70px 一级图标导航、246px 二级导航与原始项目卡片风格。功能按需展开，不堆叠新菜单。

## v6 信息架构与交互

- **智能体**：对话、群聊、智能体管理、模板中心、任务。群聊支持频道切换、聊天消息、引用、参与者（人+Agent）、新建群聊；聊天转需求须显式确认后才创建本机需求草稿。模板中心以“智能体模板/Skill 模板”切换，支持分类、搜索、预览、加入 Agent 配置草稿。
- **项目**：沿用全部七项；项目卡片和详情、需求/BUG 看板、文档、代码仓等保留。群聊右侧与中/小屏快捷栏能跳转关联项目的概览、需求看板、项目文档。
- **团队**：团队管理、成员与权限、团队设置。成员与权限内部用三标签承载“成员列表、角色权限、邀请记录”，避免多重导航。
- **个人**：个人主页、消息通知。仪表盘与任务聚焦合并在个人主页；避免重复的“我的任务/待办”侧栏入口。

## 实际修复的可用性问题

1. 模板中心的顶部搜索与页面内搜索原先不同步，现已统一查询状态，手机/桌面均可用。
2. 当群聊右侧信息面板因屏宽隐藏时，项目/需求/文档三个入口原先不可达，现由紧凑快捷栏补足。
3. 群聊转项目资源导航现在携带所在群聊的项目上下文，不会误进入另一个项目看板。
4. 群聊名/消息按文本转义展示；至少保留一名群成员；保存、转需求、添加 Skill 明确标注为本机演示。

## 来源与竞品思路

- 用户提供的项目、团队、文档、代码仓、Agent 管理/聊天、个人仪表盘和项目弹窗截图是视觉参考。
- 用户上传的《AegisTeam 超级团队竞品调研 V0.2》提供了“人+Agent 在同一工作区、消息到任务、任务到评审、权限/审计可见”的产品原则；没有复制竞品页面。
- TinyFish 未能成功获得在线研发后台的有效认证会话，不宣称对受保护页面完成现场交互复刻。未从截图确认的细节按原型假设处理。

## 测试记录（2026-10-23）

- 本地 Chromium + Playwright **页面注入模式**：320、390、768、1024、1440、1664px 六种屏宽基础回归通过，覆盖群聊、消息转需求、模板切换、成员配置、团队导航与旧项目详情。
- 对抗测试在 390px/1440px 通过：恶意 HTML 文本未被渲染成标签；群成员人数保护；搜索同步；关联项目跳转；无脚本异常。
- `node --check` 对新增 JS 语法校验通过。HTML 为单文件，内嵌 CSS/JS，无 CDN 依赖。
- **未覆盖/不得夸大**：此沙盒阻断 `file://` 导航（`ERR_BLOCKED_BY_ADMINISTRATOR`），因此尚未在真实本地打开后的刷新持久化路径验证。无生产鉴权、性能监控或完整 WCAG 认证。用户用 Chrome/Edge 打开完整 HTML 验收。
