# AragonTeam v11 · 智能体画布与画布模板交互设计锚点

日期：2026-10-26。目标仓库：`jinngimk-lang/wendnag`，工作分支 `jinngimk-lang-AT`；唯一入口：根目录 `index.html`。

## 需求与产品边界

用户提供 Figma Recent、Figma 编辑器和悬浮卡片动画参考截图，要求在既有 AragonTeam **智能体** 导航增加「画布」交互页面，在既有「模板中心」增加画布模板；**只做前端交互展示，无后端**。

一级入口必须仍为：智能体 / 项目 / 团队 / 个人（设置保留在最下面）；项目二级菜单七项保持不变：项目管理、需求看板、BUG看板、文档、代码仓、建议、版本。团队、项目、群聊、会议、个人页继承 v10，不得被新的画布页面替代。

## 信息架构与页面设计

- 智能体二级：对话、群聊、**画布**、智能体管理、模板中心、任务。
- 模板中心内保留「智能体模板」「Skill 模板」，新增「画布模板」，不添加另一个一级模块。
- 画布页面：顶部作品名称、模板库、导出 SVG、保存；桌面左侧作品/图层、中间可缩放画板和底部编辑工具、右侧属性。手机默认隐藏侧栏，点击工具栏按钮分别打开图层或属性，互斥显示。
- 画布支持：选中、拖动、右下角调整大小、添加矩形、圆形、文字、便签和画板、属性 X/Y/宽/高/填充/字号/文字、复制、删除、图层选择、平移、缩放、适配、撤销/重做、保存到当前浏览器和 SVG 下载；画布文档可新建、切换和重命名。
- 画布模板 6 项：产品规划画布、团队头脑风暴、用户旅程地图、研发协作流程、项目状态看板、灵感视觉拼板。支持类别筛选、搜索、卡片预览和一键生成可编辑内容；卡片 hover 有适度层叠动态效果，尊重 prefers-reduced-motion。
- 延续产品的浅色、深蓝文字、橙色主操作、高对比焦点和轻量边框，不直接拷贝 Figma 商标或 UI 源码。

## 专家视角与设计取舍

- **新用户**：默认展示有内容的产品规划示例，首屏即可看到画板、工具和属性；“模板库”是明确入口。
- **熟练设计者**：提供图层面板、键盘 Delete 与方向键微调、常用工具快捷键、撤销重做与 SVG 输出。
- **项目经理**：模板把讨论、任务、路线图、流程集中于一个可操作画布，不额外增加项目导航菜单。
- **移动用户**：默认仅突出画板，侧栏显式打开，不让操作面板互相遮挡；宽度不足时在画板工作区内部滚动，不造成整页横向溢出。
- **安全/真实性**：用户输入统一 HTML 转义，SVG 输出文本转义。页面明确声明“浏览器本地演示”，没有 Figma 兼容文件、多用户实时编辑、真实 AI 设计、在线发布、账号同步或外部 API。
