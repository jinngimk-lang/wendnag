## 当前对话已经讲通的知识节点

1. 符号：`x_0`、`x_t`、`T`、`q`、`p_θ`、`β_t`、`α_t`、`\bar α_t`。
2. 前向一步：
   `q(x_t|x_{t-1}) = N(√α_t x_{t-1}, β_t I)`。
3. 任意步直达：
   `x_t = √\bar α_t x_0 + √(1-\bar α_t) ε`。
4. 反向模型：
   `p_θ(x_{t-1}|x_t)`。
5. 最大似然难直接算，转为变分上界 / ELBO。
6. ELBO 分解为 `L_T + Σ L_{t-1} + L_0`。
7. `L_0=-log p_θ(x_0|x_1)` 的宏观职责：最后一步把潜在去噪链锚回真实数据空间。
8. “老师”：
   `q(x_{t-1}|x_t,x_0)` 在训练时因 `x_0` 已知而可解析计算。
9. 贝叶斯：
   `q(x_{t-1}|x_t,x_0) ∝ q(x_t|x_{t-1})q(x_{t-1}|x_0)`。
10. 两个高斯相乘仍是高斯，得到 `\tilde μ_t`、`\tilde β_t`。
11. 闭式计算与 Rao–Blackwell 化：能解析积分掉的随机性，不用 Monte Carlo 抽样估计。
12. `L_T` 与网络参数 `θ` 无关，固定 schedule 时对梯度为 0。
13. 固定反向方差后，高斯 KL 对 `θ` 有关的部分变为均值平方误差。
14. 均值参数化可改写成噪声参数化 `ε_θ(x_t,t)`。
15. 经典 simplified objective：
   `E ||ε-ε_θ(x_t,t)||²`。
16. 条件 score：
   `∇_{x_t} log q(x_t|x_0) = -ε/√(1-\bar α_t)`，因此噪声预测与 score 预测只差已知比例。
17. 训练：采 `x_0,t,ε` → 直接构造 `x_t` → 网络猜 `ε` → MSE。
18. 生成：`x_T~N(0,I)`，按 `t=T...1` 逐步采样 `x_{t-1}`。

## 精炼时必须保留的关键纠错

- KL 是散度，不是对称距离：一般 `D_KL(P||Q) != D_KL(Q||P)`。
- “真实 x0 是 one-hot”只适合离散直觉；连续图像更严谨地可理解为观测值/Dirac delta，原始 DDPM 的 decoder likelihood 也有离散化处理。
- “去噪”并不意味着采样每一步都不加随机噪声。DDPM 反向模型是条件概率分布，采样形式是 `μ_θ + σ_t z`。
- `β_t` 表示一步噪声方差；`α_t=1-β_t` 是一步保留的信号功率比例；真正乘到信号振幅上的是 `√α_t`。
- `\bar α_t=∏_{s=1}^t α_s` 是累计信号功率比例；`s` 只是乘积索引。
- 经典 DDPM 的严格 ELBO 噪声目标带时间权重；常用 `L_simple` 去掉了该权重，是训练目标的经验简化，不应说成与 ELBO 完全相同。
- 固定方差的早期 DDPM 是一种设计选择；后续扩散模型也可以学习方差或使用其他参数化（x0 / ε / v）。
