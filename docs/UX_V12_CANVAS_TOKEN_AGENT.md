# AragonTeam v12 · 画布作品库、Agent 指令及 Token 任务明细

日期：2026-10-26；仓库：`jinngimk-lang/wendnag`；工作分支：`jinngimk-lang-AT`；原型文件：仓库根目录 `index.html`。

## 本轮用户需求

用户在 v11 截图上指出：智能体任务必须能查看各个 Agent 的 Token 消耗；点击“画布”时应先打开已有画布卡片列表，选择卡片才进入编辑器；编辑器左侧需要类似 Figma 的 Agent 对话框，用于对画布直接发出修改指令。保持此前“仅前端 UI/交互演示”约束，不接后端或真实模型。

## 设计与实现

- **画布首页**：从直接进入编辑器改为展示“我的画布”作品卡片（缩略图、名称、图层数、最后编辑时间）和新建/浏览模板入口。通过 `继续编辑` 打开指定的既有画布；画布保留 v11 原有所有图形、文字、拖动、图层、颜色、缩放、撤销/重做、SVG 导出与模板生成能力。
- **保存/返回**：编辑器顶部提供“我的画布”和“保存并返回”两个清晰入口。沿用 v11 的 `aragonteam.canvas.v11` 本地数据键与已有文档格式，并兼容老文档无 `updatedAt` / `chat` 字段的情况。新建模板仍直接进入编辑器，保存后回到作品库。最多保留 18 张本地演示画布。
- **左侧 Agent**：编辑器左侧分成 Agent/图层 Tab，默认 Agent。预设快捷指令和文字输入支持 `添加便签：内容`、`添加文字：内容`、`添加矩形/圆形`、`把选中元素改为蓝色/红色/绿色/黄色等`、`修改选中文字：内容`、`画布底色改为黄色`。确定性浏览器脚本修改文档、进入撤销栈，并记录逐画布聊天记录；不符合规则的请求仅提示支持范围，不擅自更改数据。**不是模型推理**，不生成网络请求，不计费。
- **任务 Token**：智能体→任务展示总计、参与 Agent、每 Agent 使用分布及任务明细；可切换 7/30 天与 Agent。演示值为按任务 ID 与 Agent ID 计算的固定样本，始终显示“演示数据 / 非真实计费”，不可用作真实账单或 Token 审计。
- **移动适配**：320–900px 默认优先显示画板，Agent 和图层/属性面板通过按钮按需打开，Agent 面板与右属性面板互斥。再次进入画布不复用遮挡主画板的面板打开状态。
- **其他导航**：一级保持智能体/项目/团队/个人；项目七项菜单不动；智能体画布模板仍在模板中心，团队和会议功能完整保留。

## 验证与边界

- `tests/test_v12.py`：320、390、768、1024、1440、1664px 六宽度 PASS；作品库→画布→Agent 添加→撤销/重做→保存返回→重新打开→Token 按 Agent 筛选与时间切换→项目页回归。无 JS 脚本异常、无文档级横向溢出。
- `tests/test_v12_adversarial.py`：390/1440px PASS；不支持指令不可误改图层、恶意 HTML 当作文本、先选图层再改色、模板可编辑、保存返回后同会话重开保留状态、手机面板不会在重开时挡住画布。
- 由于沙盒浏览器禁止 `file://` 与 `localhost` HTTP 页面导航，而且注入模式 `localStorage` 权限不可用，**浏览器刷新后实际持久化没有自动化验证**；实际本地 Chrome/Edge `file://` 打开后需要人工复验。此限制不会被描述成通过。
- 不提供真实 AI、Token 计量、多人协作、云端保存、远程设计工具 API 或服务器功能。
