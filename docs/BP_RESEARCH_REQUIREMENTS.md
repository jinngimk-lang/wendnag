# 智瞳安宇 BP 对标研究与改版任务总纲

> 本文件是本轮及后续上下文恢复的最高优先级需求锚点。任何继续工作的 Agent / ChatGPT 在上下文较长、切换会话或对任务方向不确定时，应首先重新阅读本文件，再继续执行。

## 1. 用户目标

围绕西安智瞳安宇科技有限公司现有 BP（Business Plan / Pitch Deck）进行一次完整的“现状审阅 → 全网对标 → 结构化比较 → 改版建议 → 资料归档”研究。

核心目标不是简单收集案例，而是借助优秀互联网、AI 软件、AI 基础设施、具身智能/机器人/智能硬件公司的融资材料，找出智瞳安宇现有 BP 在叙事、证据、产品表达、市场、商业模式、竞争壁垒、团队、融资需求与视觉呈现方面最需要修改的地方，并形成可以直接指导下一版 BP 制作的详细报告。

## 2. 必读范围：先完整理解本仓库现有 BP

1. 阅读仓库内所有与公司 BP、融资、公司介绍、产品、市场、技术、团队、财务、融资有关的文字文件。
2. 阅读现有 BP 中的图片、图表、架构图、产品截图、视觉页面，而不仅是文字。
3. 对每页/每个主要章节记录：
   - 这页想表达什么；
   - 投资人能获得什么信息；
   - 证据是否充分；
   - 是否存在表述模糊、堆概念、缺数据、缺因果链、缺竞争差异化等问题；
   - 视觉信息是否帮助叙事。
4. 仓库现有内容是判断“智瞳安宇当前 BP”的事实源，不得凭空补造公司数据。

## 3. 全网寻找 10 份高相关 BP / Pitch Deck / 融资材料

### 3.1 方向
优先寻找与智瞳安宇业务方向相近、或在融资叙事方法上高度可借鉴的公司：

- 互联网平台 / AI 软件；
- 生成式 AI / AI Agent / AI 基础设施；
- 设计软件 / 协作软件；
- 具身智能 / 通用机器人 / 人形机器人；
- AI + 智能硬件；
- 感知、计算机视觉、边缘 AI、机器人平台等。

### 3.2 用户点名参考
优先调查并判断是否存在可公开验证的融资材料：

- 字节跳动 / ByteDance；
- Figma；
- OpenAI；
- “A 社”——默认优先按 Anthropic 调研，如证据显示用户语境中更可能指其他公司，再调整；
- 以及其他与智瞳安宇更匹配的头部公司与优秀初创公司。

### 3.3 样本选择原则
最终 10 份样本要兼顾：

- 头部 / 标杆公司与早期初创公司；
- 软件与硬件；
- AI 与具身智能；
- 不同融资阶段；
- 公开来源可信度；
- 与智瞳安宇的可比性。

如果某个点名公司没有公开可验证的正式 BP，不得伪造或用二手“仿制 deck”冒充官方 BP。可将其公开融资 memo、官方投资者材料、创始人融资叙事、可信数据库中的公开 deck 作为补充研究，但必须在来源表中明确材料性质和可信等级。

## 4. 版权与归档规则

1. 对公开可下载且允许再分发/具有明确开放许可/官方公开发布的材料，可在仓库研究目录中保存原文件或合法副本。
2. 对版权受限、来源条款不明确、仅可在线浏览的第三方 BP：
   - 不在仓库重新分发整份原版；
   - 保存官方/原始来源链接、来源信息、关键页面编号和研究笔记；
   - 可以进行逐页中文“释义/总结/结构还原”，但不逐字复制或完整翻译受版权保护的原文。
3. 最终资料包应包含：
   - 可合法归档的原始公开资料；
   - 其余材料的来源索引；
   - 每份材料的中英文对照研究笔记 / 中文释义；
   - 总体对比报告。

## 5. 每份 BP 的研究输出

每个样本至少记录：

- 公司 / 产品；
- 年份 / 融资阶段；
- 材料类型（官方 deck、公开 deck、投资 memo、投资者材料、可信二手公开材料等）；
- 来源 URL；
- 来源可信等级；
- 页数（若可得）；
- 核心叙事顺序；
- Problem / Solution；
- Why now；
- 产品演示方式；
- 市场规模表达；
- 商业模式；
- Traction / 关键经营数据；
- 技术或数据壁垒；
- 竞争分析；
- Go-to-market；
- 团队；
- 融资金额 / 用途（若公开）；
- 视觉设计特点；
- 最值得智瞳安宇学习的 3–5 点；
- 不应照搬的部分。

英文材料：在研究笔记中采用“英文页面/段落核心意思 → 紧邻中文释义”的双语方式，确保中文读者可以完整理解其融资叙事，但避免对受版权保护材料做大段逐字复制。

## 6. 智瞳安宇对比报告

最终必须形成详细对比文档，至少包括：

### 6.1 总览表
以表格比较智瞳安宇与 10 家公司，维度至少包括：

- 一句话定位；
- 目标客户；
- 核心问题；
- 核心产品；
- AI / 软件 / 硬件占比；
- 价值主张；
- 市场；
- 商业模式；
- Traction；
- 技术壁垒；
- 数据壁垒；
- 生态 / 平台壁垒；
- 竞争差异化；
- GTM；
- 团队说服力；
- 融资叙事；
- 视觉表达；
- 对智瞳安宇的可借鉴度。

### 6.2 逐章节诊断
针对智瞳安宇现有 BP 的每个核心章节给出：

- 当前表达；
- 对标公司通常怎么表达；
- 当前问题；
- 修改目标；
- 建议的新结构；
- 需要补充的数据/证据；
- 推荐图表/视觉；
- 可直接用于下一版 BP 的页面标题或文案骨架。

### 6.3 优先级
建议按 P0 / P1 / P2 分级：

- P0：影响投资人是否继续看、是否相信公司价值的关键问题；
- P1：显著增强说服力、数据可信度和竞争壁垒；
- P2：视觉、措辞、细节优化。

### 6.4 最终建议应回答

- 智瞳安宇应该被投资人记住成“一家什么公司”？
- 当前 BP 最大的叙事断点是什么？
- 哪些页面应该删除、合并、新增或重做？
- 哪些数字必须补证据？
- 哪些产品与技术能力需要从“功能列表”升级为“独特能力 / 壁垒 / 商业价值”？
- 软件、AI 与具身智能硬件三条线如何统一成一个投资故事，而不是三个平行项目？
- 下一版 12–18 页融资 BP 的推荐页序是什么？
