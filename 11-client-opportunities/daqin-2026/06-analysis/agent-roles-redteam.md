# 十个研究 Agent 的职责与挑战（研究岗位，不代表后台实例）
| 角色 | 负责搜集的实据 | 当前发现 | 必须主动寻找的反证 |
|---|---|---|---|
| 01 集团战略 | 工商主体、旗下品牌、治理、投资事件 | 2026新研发及厂区布局[S08/S09] | 真实投资进度/谁能签约 |
| 02 品牌IP | 商标、民刑事司法、警方、公证、侵权店铺 | [S01-06]多源证实历史案件和取证流程 | 2026是否已有成熟取证工具 |
| 03 销售组织 | 直营/经销模式、经理培训、区域目标 | 历史地推获客与销售组织[S07/S10] | 成本真实构成/是否仍是痛点 |
| 04 私域复购 | SCRM和小程序、生命周期指标 | 腾讯企点历史供应商[S07] | 现有模块是否已经全部覆盖 |
| 05 质量制造 | 品类、厂区、检测报告、质量责任 | 新基地协同[S09] | 不能虚构质量异常或QMS缺失 |
| 06 合成生物研发 | 研究院、专利、实验资料、合作 | 2026研究院[S08] | 不把科学实验能力当现成AI产品 |
| 07 采购供应链 | 库存、跨厂供应、招标及供应商 | 公开资料不足 | 不凭推测建预测系统 |
| 08 广告合规 | 产品类别、消毒宣称、包装标签、规则 | 强监管表达存在合理适配点 | 不能声称已发生罚款 |
| 09 B端商务 | 公共采购、经销商、招投标、回款 | 第三方采购合同有优露清品[S11] | 成交供应商非品牌公司，是否增量? |
| 10 红队/交付 | 产品事实、存量供应商、ROI、权限 | 发现InkClaw/AegisClaw名称差异[S12] | 既有供应商、高集成量、无预算直接否决 |

## 交叉审查规则
**事实的来源是什么？** → **2026是否仍然成立？** → **经营损失/增量可否计算？** → **决策人与预算在哪里？** → **客户现有系统覆盖到哪里？** → **智瞳产品能否在合规环境重现？** → **POC何时退出？**

每条角色结论必须把观察、推断、未知分开，不能因多Agent“投票多数”替代可复核证据。
