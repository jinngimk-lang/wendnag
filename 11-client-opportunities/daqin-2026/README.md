## 长期需求锚点（必须先读）
用户目标：以智瞳安宇的真实产品能力研究大勤实业的**企业级重大经营痛点**，不能堆砌通用 AI 功能；10 个研究角色分别调查全价值链，搜尽司法、监管、新闻、公司、招采、供应商、质量、研发等证据。最终优先级必须由**真实痛点→经营价值→预算/决策人→产品适配→可测 POC→排他/替代风险**决定，不能预先强行锁定打假。

## 案例样本
用户提供《巨子生物 AI 落地与定制化开发机会》20页 PDF，作为**分析结构样本**，非大勤事实依据。其缺点之一是外部重大事件搜索遗漏；本项目建立“多源覆盖→反证搜索→验证截止”纠错机制。

## 工作要求
- 10 个研究岗位的假设、事实、反方质疑单独列档；不得声称 10 个独立后台 Agent 已运行。
- 官网/法院/检察/政府原始文本优先；对公司自述、合作方案例、转引资料分别标注。
- 评分是分析工具而非大勤真实绩效；硬性否决：无重大损失/增量、已有供应商覆盖、无数据权限、无法验收、超出已证实产品能力。
- 原始私有 PDF 与潜在内部商业信息不直接上传**公开**仓库。
- 咨询式图表由 Python/SVG **确定性生成**，保存 SVG + 可编辑源码；不得用生图替代原始判决或产品真实截图。
- 分支完成后先交 PR 并检验，安全通过再按仓库流程合并。
- 所有文件按日期、版本归档，记录下一步、未核实项、失败尝试，避免上下文丢失。
