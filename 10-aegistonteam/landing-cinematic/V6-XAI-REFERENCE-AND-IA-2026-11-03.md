# AegistonTeam V6 — x.ai 信息架构参考与映射

> 日期：2026-11-03  
> 状态：已实现本地 review candidate；等待用户视觉验收  
> 参考来源：[x.ai](https://x.ai/)（公开首页，2026-11-03 检查）

## 1. 从 x.ai 提取的结构规律

本轮只借鉴内容层级与板块顺序，不复制品牌视觉、文案或产品主张。

观察到的公开首页顺序：
1. 精简导航：产品、下载、开发者入口与主 CTA。
2. Hero：强价值主张、简短能力说明、两个主要行动入口。
3. 产品交互展示：用多个产品入口/演示让用户快速理解产品范围。
4. 能力总括：以一个清晰的大命题解释产品如何连接不同能力。
5. 证明层：指标、代码示例等，让能力有可理解的证据。
6. Latest news：展示可核实的近期产品发布。
7. Choose how to get started：给出两种清晰的开始路径。
8. Footer：按产品、解决方案、开发者、企业、信任与公司信息组织。

## 2. 映射到 AegistonTeam

| x.ai 的内容角色 | AegistonTeam V6 的映射 | 真值依据 |
|---|---|---|
| Hero + CTA | 「让好点子，开始一起工作」+ 原创三人小队 + 产品/协作 CTA | 用户批准的暖白漫画视觉锚点 |
| 产品交互展示 | 工作台 / 团队结构真实截图切换与放大 | 用户提供的真实产品截图 |
| One API. Every modality. | 「一个空间，三种协作时刻」：灵感、推进、团队 | AegistonTeam 项目定位与既有界面 |
| 指标 / 代码示例 | 三条协作原则 + 团队结构与工作流程证据 | 用真实能力代替未经批准的性能指标/API 主张 |
| Latest news | 不伪造新闻；以产品工作流程与真实界面作为内容证明 | 当前没有经核实的公开产品新闻清单 |
| Choose how to get started | 「从工作台开始」/「从团队结构开始」两条入口 | 当前页面内可用的真实内容锚点 |
| Footer | 原创三人伙伴奔跑动画与品牌收尾 | 已批准的角色资产与 V5 动效 |

## 3. 视觉与内容边界

- 保留暖纸白、橙色强调、石墨色文字与用户批准的橙/奶油/深灰三人卡通素描。
- 不切换深蓝科技风，不照搬 x.ai 的 Grok 产品 UI、品牌文案或图形。
- 产品截图保持真实像素与原始文字，不生成虚构界面。
- 不虚构用户数、效率提升、API、客户、性能、安全、新闻或部署能力。
- 不将装饰性角色卡描述成已经交付的 Agent 自动执行功能。
- 当前是前端产品介绍原型，不是线上正式网站。

## 4. 页面顺序（V6）

1. Hero
2. 真实产品工作台预览
3. 三条协作原则（替代虚构的数字指标）
4. 三种协作时刻（不对称插画布局）
5. 团队结构与交互式工作流程
6. 两种开始路径
7. 吉祥物奔跑收尾与页脚

该顺序保留 x.ai 的「先价值、再演示、再能力证明、最后给出开始路径」节奏，同时按 AegistonTeam 的真实产品内容进行适配。
