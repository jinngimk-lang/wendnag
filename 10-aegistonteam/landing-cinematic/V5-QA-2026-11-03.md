### Environment limitation

The container has no DNS/network access; installing extra packages into the project venv and cloning the repository locally were unavailable. Browser QA used the preinstalled Python Playwright environment and system Chromium. Direct `file://` navigation is blocked by administrator policy, so the exact HTML bytes were tested via Playwright `page.set_content`. This validates document rendering and embedded assets but is not a direct double-click test of the local file.
