# AegistonTeam · 产品设计与演示修改要求

> 建立日期：2026-10-28｜状态：演示讨论草案，不是最终确认的产品视觉规范。

## 目标

**强化产品辨识度，统一产品布局、网站配色和吉祥物视觉。**

| 重点 | 要求 |
| --- | --- |
| 产品辨识度 | 用户一眼认出 AegistonTeam；统一 Logo、图标、视觉语言、交互反馈，避免通用后台模板感。 |
| 产品统一布局 | 统一一级/二级导航、页面标题、卡片、表格、按钮、弹窗、空状态的布局和交互逻辑。 |
| 网站配色 | 上传 HTML 的后续品牌样式含强调橙 `#D75F35`、浅灰背景 `#F3F5F9`、深色文字 `#292622`、白色卡片 `#FFFFFF`。这些是**现有原型观察**，最终色值需另外确认。 |
| 产品吉祥物 | 沿用原型的橙色吉祥物家族，统一角色设定、比例、材质、表情、配色和场景；用于欢迎、引导、空状态、智能体与协作，不压过核心信息。 |

## 上传 HTML 的可恢复页面结构

原型的一级导航为 **智能体 / 项目 / 团队 / 个人 / 设置**。

| 一级导航 | 原型 `menus` 内定义的二级导航 |
| --- | --- |
| 智能体 | 对话、智能体设置、智能体模板、智能体任务 |
| 项目 | 项目管理、需求看板、BUG看板、文档、代码仓、建议、版本 |
| 团队 | 团队管理、成员管理、角色权限、邀请记录、团队设置 |
| 个人 | 个人主页、我的任务、消息通知 |
| 设置 | 基础设置、通知设置、权限与安全 |

备注：该菜单来自 HTML 内的配置；部分展示文案可能被后续脚本动态替换（例如同一个入口可能被显示为不同业务名称）。需要修改时应以实际浏览器呈现及具体操作路径为准。
