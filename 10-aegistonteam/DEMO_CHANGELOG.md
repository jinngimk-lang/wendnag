## 填写说明

- **动作**：新增 / 删除 / 调整 / 保留。
- **优先级**：P0 必须 / P1 优先 / P2 后续。
- **状态**：待确认 / 待修改 / 修改中 / 已完成 / 暂缓。
- 一条需求占一行，记录“现状 → 期望 → 验收方法”，不把待讨论想法当成已确认的决定。
