# 多平台宣传视频深挖 — Checkpoint 03：直接视频观察

日期：2026-09-23  
分支：`research/video-content-deep-dive-20260923`

## 1. 本轮新增证据

通过 GitHub Actions + MIT 许可的 `zyipeng/video-downloader` 对用户表格中的公开链接做小规模研究解析。

结果：
- 快手 2026-06-15 / 06-16 / 06-17 / 06-19 凌晨 / 06-19 晚间共 5 条均成功解析和取得研究用低清视频；
- 已抽取代表帧、音频和 ffprobe 元数据；完整视频没有提交到仓库；
- 抖音短链均能解析到真实 `douyin.com/video/<aweme_id>`，但第三方 SSR 解析器因抖音分享页结构变化未能提取 `play_addr`；
- 小红书短链均能解析到真实 item id + xsec_token，但匿名 GitHub runner 被导向登录页；
- 视频号公开短链页面只能取得通用“视频号”页面标题，未暴露可验证视频元数据。

因此，本轮对“原视频实际内容”的直接观察主要来自**与其他平台同批发布的快手版本**。根据原表，同一批内容基本属于同一创意核，但不能武断认为四个平台成片逐帧完全一致。

## 3. 逐条直接观察

### 3.1 06-15：宠物个人站

代表画面链：
1. 成品页面直接出现：PawMate、“让毛孩子遇见命中注定”，前景还有机械手/玩偶；
2. 页面继续展示成品网站；
3. 中段出现明显空白/等待状态；
4. 再回到网站局部；
5. 结尾切到开发/浏览器工作区并强调“一共过了多久”。

字幕可见句包括：
- “现在还有人为做这样的个人站而头疼”
- “就这样然后就这样”
- “看看现在一共过了多久”

直接观察：
- 有“成品先行”，但开头同时出现机械手、宠物站、个人站等多个信息点，核心收益不够单一；
- 中段有等待/空白画面，降低单位时间信息密度；
- “个人站”痛点与账号此前金融/AI工具语义不一致。

这与表中四平台整体低流量一致，但**不能只归因为跨赛道**；内容本身也存在信息焦点分散和空白等待段。

### 3.2 06-16：金融分析

代表画面链：
1. 第一屏就是股票/公司分析表和明确数字；
2. 很快切到 InkClaw 首页“写得更好。想得更清。交付更快。”；
3. 展示向 AI 提出金融分析问题，回答里出现论文/资料引用；
4. 回到结构化金融分析表；
5. 最后展示一整页多图表分析报告。

字幕可见句包括：
- “这三只做出的各种信息”
- “通过刚才的问答”
- “那金融分析已经…”

直接观察：
- 开头几乎没有铺垫，先给用户最关心的“股票分析结果”；
- 过程不是抽象说“AI 很强”，而是出现真实提示词、资料检索、表格和最终报告；
- 结尾视觉证明强：多图表报告明显比聊天框更像“交付物”。

这条在抖音 10,002，是“结果先行 + 真实工作流 + 可见交付物”最清晰的样本之一。

### 3.3 06-17：NVIDIA / 金融深度分析

代表画面链：
1. 一开始就是“英伟达 Q3 财报与市场分析”等长结构化输出；
2. 随后出现醒目的绿色/红色可视化图；
3. 中间再次展示提示输入/任务派发；
4. 生成详细表格与要点；
5. 结尾展示“英伟达近期催化剂”卡片/列表。

字幕可见句包括：
- “帮我们去缩短这样的距离”
- “我们将这一串发给他”
- “然后给我们制作一个详细的表格”
- “关于英伟达接下来的合作…”

直接观察：
- 这条不是单一聊天界面，而是“文本研究 → 数据可视化 → 指令 → 表格 → 催化剂列表”的多形态证明；
- 主题词 NVIDIA/财报/合作/催化剂具备高语义集中度；
- 信息非常密，但对非金融用户理解门槛也高。

抖音 8,475，继续支持“强题材语义 + 多层结果证明”的组合在当时有效。

### 3.4 06-19 凌晨：HBM / 探索型金融研究

代表画面链：
1. 首屏是大段密集研究文字；
2. 继续在报告内容里推进；
3. 中间回到一个几乎空白的 AI 对话起始页；
4. 后续生成“美股 HBM 卖铲人近 3 个月”等表格；
5. 结尾仍以长文本输出为主。

字幕可见句包括：
- “他就会再接着去帮咱们去探索”

直接观察：
- 与 06-16/17 相比，首屏“可一眼读懂的结果”更弱；
- 视频更长（65.1s），而中段又出现空白/重新开始的视觉状态；
- 核心价值更偏“AI 会继续探索”，不如“马上得到一张明确报告”具体。

其抖音只有 1,271，说明在同一金融语义中，**包装和视觉交付形式仍可能造成一个数量级的差异**；发布时间也同时变化，不能单独归因。

### 3.5 06-19 晚间：每个人都可能是金融分析师

代表画面链：
1. 首屏就是 WOLF / COHR / ANET 等结构化表格，并通过手绘圈选强调关键区域；
2. 很快出现更完整的股票分析；
3. 中段出现英文提示词/检索任务；
4. AI 生成过程；
5. 结尾是带 emoji、技术指标和结论的丰富结构化结果。

字幕可见句包括：
- “朋友们”
- “每个人都可能是金融分析师”
- “他会立刻去搜索相关的合作情况”
- “然后我们让它生成更直观的图表”

直接观察：
- 44.8s，是五条中最短；
- 首屏即结果，并有手绘圈选制造注意焦点；
- “每个人都可能是金融分析师”把产品能力翻译成了用户身份/收益，而不是功能名；
- 过程仍然保留“搜索 → 生成 → 图表/技术指标”的可验证链路。

这条抖音 11,100，为五条最高；但快手只有 2，是最强的“同素材/同创意核跨平台结果完全不同”反例之一。

## 4. 新增的强结论

### 4.1 “结果先行”比“产品先行”更符合这批成功样本

高抖音流量样本 06-16、06-17、06-19 晚间都在很早阶段展示：
- 股票名称/数据；
- 表格；
- 报告；
- 财报或催化剂；
- 明确的分析结论载体。

不是先用十几秒介绍“InkClaw 是什么”。

因此后续应优先测试：
**结果画面 → 问题/冲突 → AI 如何做到 → 最终交付物 → 品牌归因**。

### 4.2 “真实交付物密度”可能是比“AI人物感”更重要的变量

成功样本持续出现：
- 真实 UI；
- 数据表；
- 搜索/资料；
- 图表；
- 文档/报告。

这类“证据帧”占比很高。

这为后期 AI 人物剧情广告表现弱提供了更具体的替代解释：
并不一定是“AI人物被限流”，而可能是**真实产品证明帧比例过低**。

### 4.3 “用户身份升级”是值得单独测试的 Hook

“每个人都可能是金融分析师”比：
- “这个功能可以分析股票”
- “AI 帮你做报告”

更接近一个身份型承诺。

外部高热样本也频繁使用：
- “我做了一个……”
- “零基础也能……”
- “AI 到底能替你干多少活”
- “让 AI 像……一样……”
- “一句话搞定……”

共同点不是夸张，而是让用户立刻理解**谁获得了什么新能力**。

### 4.4 同类内容内部也有“可读结果”与“密集过程”的区别

06-19 凌晨与晚间都属于金融分析，但前者：
- 首屏是密集文字；
- 中间出现空白页；
- 65s；
- 用户收益表达较弱。

晚间：
- 首屏表格；
- 圈选；
- 45s；
- 身份型 Hook；
- 结尾技术指标/图表。

因此“金融题材本身”无法解释 1,271 vs 11,100。

## 5. 已筛高热/高互动对照样本

以下公开 Bilibili 页面用于**创意结构比较**，不用于推断抖音/快手算法：

1. 《我用AI，做了个全网AI热点捕捉器！N8N工作流分享》
   - 公开页面抓取时约 19.8 万播放；
   - 核心结构：我做出了一个明确工具 → 24h 跟踪 → 过滤 90% 噪音 → 每天 9 点推送；
   - “产品能力”被包装为一个具体日常结果。

2. 《我做了一个能自动剪口播的AI Agent...》
   - 公开页面抓取时约 7.4 万播放；
   - 页面同时显示数千级点赞/收藏类互动；
   - 标题直接是“我做了一个能做事的 Agent”，不是技术名词堆砌。

3. 《WorkBuddy Agent保姆级教程：…桌面AI Agent到底能替你干多少活、WorkBuddy实测教程》
   - 公开页面抓取时约 21 万播放；
   - 简介直接列 3 个真实办公任务：游戏出海调研并生成 Word、批量产品评价生成 Excel、飞书行业动态自动简报；
   - 结构天然适合 B2B 产品：问题不是“有什么功能”，而是“能替你完成哪些交付”。

4. 《一口气学会 Vibe Coding AI 编程！从开荒到做出第一个项目》
   - 公开页面抓取时约 44.1 万播放；
   - 页面显示约万级点赞/收藏类互动；
   - 标题以“做出第一个项目”为终点，而不是“介绍 Cursor”。

5. 《零基础入门vibe coding！如何搭建自己的工作台？附指令模版》
   - 公开页面抓取时约 3.5 万播放；
   - 核心承诺：“零基础 + 自己的工作台 + 指令模板”，同时解决门槛、结果和可复制资产。

6. 《从自动写代码到智能影音刮削：实测 OpenCode，这台“赛博管家”真的能干苦力活》
   - 公开页面抓取时约 6.3 万播放；
   - 通过“苦力活”这一普通人痛点，把多个技术能力串成一个生活化角色。
