## 表格版式

原 DOCX 的所有原生 Word 表格继续保持为**可编辑表格**，不转为不可编辑的截图。统一执行：
- 深蓝表头 + 白色文字；
- 首列淡蓝强调，正文使用轻量隔行底色；
- 按每张表内容重新分配列宽；
- 长表启用重复表头并禁止单行跨页断裂；
- 表题与下一张表保持同页，避免“表题在上一页、表格在下一页”；
- 中文使用等线/现代无衬线风格，英文与数字使用 Aptos，统一字号与行距。

## SVG 可编辑性门槛

GitHub Actions 对每张 SVG 自动检查：
1. 文件必须包含 `<text>` 节点，确保文字没有被转成轮廓路径；
2. SVG 中不得出现 `InkClaw`；
3. 同时输出高分辨率 PNG 作为兼容与演示备用；
4. 关键数据图继续使用原 BP 数据口径，不因视觉优化改变事实。
