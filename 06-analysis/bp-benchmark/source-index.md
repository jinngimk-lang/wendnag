## 版权/打包说明

用户要求“把找到的 BP 全部打包”。本研究会打包：

1. 每家公司一份中英文研究档案；
2. 官方/原始来源 URL；
3. 对应的材料性质、可信等级、关键页/关键章节索引；
4. 智瞳安宇总对比报告与比较矩阵；
5. 对允许明确再分发的材料可放原件。

但本轮发现的多个原版 deck（Agility、Matterport、Sarcos、Berkshire Grey 等）在材料自身明确写有 confidential / proprietary / 禁止复制分发等条款；其他早期 deck 也没有明确开放再分发许可。因此仓库和最终 ZIP **不重新上传或复制这些整份受版权/传播限制的原版文件**，而是提供直接来源、研究摘要和中文释义。这样可以保证研究可复核，又不把“公开可访问”错误等同于“允许二次分发”。
