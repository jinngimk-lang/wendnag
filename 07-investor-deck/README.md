# 智瞳安宇 Pre-A 投资人主 Deck V1

本目录记录 2026-09-04 生成的第一版横版投资人主 Deck。目标不是把现有 31 页长 BP 横向排版，而是重构成投资人可以顺序完成判断的 **16 页 Pre-A 主融资材料**。

## 参考原则

### 结构骨架：华擎（武汉）通信科技 Pre-A BP

核心流程沿用项目已经确认的结构锚点：

> 项目总览 → 产品/应用 → 市场/痛点 → 核心能力 → 竞品/壁垒 → 团队/客户 → 融资 → 资金用途 → 经济结果 → 里程碑

华擎逐页研究见：`../05-benchmark/sources/11-huaengine-2019-prea.md`。

### 表达密度：Notion 2013 Seed Deck

只吸收“一个页面只讲一个主要结论、少字、强概念、快速理解”的方法，不复制 Notion 的文字、图形或模板。

## 智瞳安宇自己的主线

本版把公司故事收束为：

> **让企业智能体真正进入生产：身份、权限、流程、审计一体化的企业 Agent 生产底座。**
>
> 先由 LegalLens 在合同审查核心流程里的量化结果证明价值，再把同一底座复制到组织级与通用企业工作流。

因此，本版主动做了以下结构调整：

1. LegalLens 从“三个并列产品之一”提升为商业楔子；
2. 中通服陕西的量化客户证据前置到第 5 页；
3. AragonTeam / AegisClaw 作为底座向更多工作流扩张的产品化路径，而不是首页并列展示；
4. 技术章节只保留投资人能理解的四类商业壁垒；
5. 市场页减少宏观预测，强调受监管企业的实际运行条件与账户内扩张；
6. 融资用途改成“资金 → 能力跃迁 → 可验证里程碑”；
7. 所有尚未实现的收入、定价、客户目标明确标为“规划测算”。

## 视觉方向

- 16:9 横版；
- 主色：深海军蓝 / 白 / 淡蓝；
- 关键客户、技术、团队、结尾页使用低饱和企业实拍摄影感背景；
- 数据图、时间轴、竞争象限、产品结构均为 PPT 原生矢量图形，可继续编辑；
- 背景摄影只承担情绪与场景，不承载业务事实；
- 不使用科幻脑、悬浮 HUD、霓虹机器人等廉价 AI 视觉。

摄影背景为本轮根据页面语义单独生成的视觉资产；因仓库当前二进制交付政策，PPTX/PDF 与照片背景本体在对话中交付，仓库保存结构、设计说明和校验记录。
