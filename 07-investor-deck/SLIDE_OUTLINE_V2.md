# 智瞳安宇 Pre-A 投资人主 Deck V2 — 21 页结构

V2 是对 V1 的内容与视觉重构，不再采用大量“多人会议/商务合影”生成背景。目标：**信息密度提高、真实产品证据增多、背景退居辅助、官网与产品介绍视觉优先。**

## 叙事主线

> 市场在长、范式在变 → 企业 AI 卡在生产化 → 根因是组织制度/系统缺一层 → 智瞳安宇提供企业 AI 原生人机协同操作系统 → 一个底座三层产品 → LegalLens 先证明商业价值 → 通信/交通证明可量化与可复制 → AragonTeam/AegisClaw 扩张 → 技术/私有化形成准入壁垒 → 共建沉淀成行业模板 → GTM/商业模式 → 团队 → 融资与下一阶段里程碑。

## 21 页

1. **封面 / 投资命题**：让企业智能体真正进入生产；企业 AI 原生人机协同操作系统；Pre-A ¥1,000 万 / 10%。
2. **投资摘要**：定位、产品、团队、客户、复制、融资六块硬信息。
3. **Why Now**：$6.76B → $46.04B、47% CAGR、22 亿 Agent、中国政策普及率 + “智能不再稀缺、组织与判断成为瓶颈”。
4. **四重困境**：工具孤岛、治理缺位、流程失配、数据主权；结论“5% 与 95% 的差别，不在模型，在组织”。
5. **组织 OS**：员工 / Agent / 企业知识 / 业务流程 + 治理与边界 / 组织记忆 / 协同调度 / 反馈与归因。
6. **产品体系**：LegalLens、AragonTeam、AegisClaw，共享身份/权限、知识/上下文、流程/状态、审计/留痕。
7. **LegalLens 商业楔子**：解析 → 审查 → 校验 → 证据 → 沉淀；五类高发风险；真实产品视觉。
8. **通信客户证据**：3.5h→10m、35→105+、500+、1280、86%，12 个月共建，陕西→福建/湖北/湖南。
9. **交通第二样板**：1天→10m、-64%、41%→73%、集团+13 子公司、11 类合同、73 规则、49 风险闭环。
10. **LegalLens 产品证据**：真实界面三联图，强调产品化而非“架构方案”。
11. **AragonTeam**：研发/项目交付闭环；需求→规划→开发→测试→修复→验收；正式身份、版本、知识、重入、私有化。
12. **AegisClaw**：文件边界、命令策略、资源约束、长任务、DAG/网页/文档/云沙箱；正文统一当前名称。
13. **技术壁垒**：异构治理、运行图长稳执行、AragonMesh/KV-Cache、法律推理/可信输出；翻译成商业结果。
14. **私有化/一体机/安全**：私有服务器、便携一体机、私有云、公有云；四层安全防御。
15. **复制飞轮**：首单共建→沉淀资产→行业模板→复制扩张→账户扩张。
16. **商业模式**：四条收入线与规划价格；显著标注“规划测算”。
17. **GTM**：战略合作伙伴、行业样板、高校/地方科技体系；标准私有化交付五步。
18. **竞争格局**：类别比较，不新增未经核验的具名竞品事实；核心组合为治理运行时+长流程+行业资产+私有化。
19. **团队**：李金库 Founder-Market Fit + 焦瑞/冯哲轩/贾皓/李天羽；20+ 研发、30+ 公司自有核心技术。
20. **融资与里程碑**：¥1,000 万 / 10%；40/20/20/12/8；0–12、12–24、24–36 月能力跃迁。
21. **收口**：Why now / Why us / Why this round。

## V2 相对 V1 的关键变化

- 16 页扩为 21 页，不再为了“极简”牺牲事实密度。
- 增加产品证据页、组织 OS 页、准入/部署页、独立 GTM 页。
- 前 10 页连续完成“趋势 → 痛点 → 解法 → 产品 → 客户结果 → 第二行业验证 → 产品实物证据”的判断链。
- 背景视觉不再以人物为主；封面/结尾使用品牌化抽象网络，正文以原生图表、真实产品界面和轻量底纹为主。
- 官网仓库 `AegistonWEB/frontend/public/media/product/` 中已有大量 `ara-*` 产品素材；`media/stock/` 也有 about/deployment/contact 等背景素材。正式下一版若二进制资产可直接同步到构建环境，应优先使用这些官网资产。
